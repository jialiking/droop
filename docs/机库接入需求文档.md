## 1. 设计原则（核心 vs 次要）

按机库值班/作业场景，以「是否影响安全、是否处于出入库主链路、是否高频点按」三维打分：

| 级别 | 判定 | UI 形态 |
|------|------|---------|
| **L0 安全** | 急停、工作模式、联锁提示 | 常驻高亮卡 / 横幅，一键可达 |
| **L1 作业主链路** | 开关门、升降、在位/充电、出/入库、飞机开关机、充电起停 | **主区卡片 + 主操作按钮** |
| **L2 状态确认** | 归中/充电夹具、出/入库完成、复位完成、市电、平台心跳 | 主区**紧凑指标卡**（只读） |
| **L3 细节与微调** | 温湿度明细、雨雪枚举原文、心跳序号、归中/夹具/遥控器/空调/重启工控机/复位等 | **点击展开弹窗**（状态明细 + 次要指令） |

> 结论：页面上直接露出的是 **安全 + 作业闭环**；弹窗里是 **调试、维保、环境明细、机构点动**。

| `lifting_platform_down` | 升降下降 | A | 主按钮 |

### 4.2 L0 — 安全常驻（横幅，不进弹窗）

| method | 动作 | 说明 |
|--------|------|------|
| `stop` | 急停 | 常驻红色主按钮 |
| `clear_emergency_stop` | 清除急停 | 联锁 ON 时唯一可点主操作 |

### 4.3 L3 — 弹窗「更多控制」（低频/维保/点动）

| method | 动作 | 分组 |
|--------|------|------|
| `position_center_close` / `position_center_open` | 归中夹紧/松开 | 机构点动 |
| `charging_center_close` / `charging_center_open` | 充电伸出/缩回 | 机构点动 |
| `door_center_clamp` / `door_center_release` | 顶门归中夹紧/松开 | 机构点动 |
| `remote_control_turn_open_off` | 遥控器开关机 | 外设 |
| `air_conditioner_close` | 关空调 | 环境设备 |
| `reset` | 机场复位 | 系统 · **危险·二次确认** |

**UI 规则**：主区永不平铺全部 21 个 method；L3 一律进弹窗，避免误触维保指令。

## 5. 安全联锁（L0，与协议一致）

- 清除急停信号 **ON**：
  - 仅 `clear_emergency_stop` 可下发；
  - 其它 method 一律拒绝，文案：`清除急停信号为 ON，请先将其置为 OFF。`
  - 主区按钮禁用 + 横幅红色说明；弹窗内次要指令同样禁用。
- 信号 **OFF**：L1/L3 可执行。
- `stop` 在联锁 ON 时**默认仍可点**（安全优先，**待你确认**）。
- `dock_work_mode=3` 或 `stop_state=true`：与安全横幅联动高亮。

## 6. 通信与数据（不变，摘要）

| Topic | 用途 |
|-------|------|
| `th/product/all/broadcast` | `heart_beat`，>10s → PLATFORM HB OFF |
| `th/product/{sn}/osd` | OSD，约 2s |
| `th/product/{gateway_sn}/services` / `_reply` | 指令与回执 |

请求：`tid`/`bid`（带横线 UUID）+ `method` + `timestamp` + `gateway`。  
回执：`data.result` 0/-1，失败带 `message`。

完整字段与枚举见协议；前端类型见 §8。

## 7. 功能需求（按交付优先级）

### FR-1 机库主面板（P0）— 卡片直出

- 安全横幅（L0）+ 卡片 A/B（L1 指令与状态）+ 卡片 C/D（L2 紧凑只读）。
- OSD mock 周期约 2s 刷新；运动中（`*_state=3`）胶囊动画。
- 主按钮点击 → 模拟 services_reply → Toast。

### FR-2 「更多控制 / 明细」弹窗（P0）

- 入口：卡片 D 右上「环境与更多明细」、卡片 B/A 可选「更多控制」。
- 内容：§3.3 明细表 + §4.3 次要指令分组按钮。
- 弹窗内危险 method（`reset`/`restart_pc`）仍需二次确认。
- 联锁 ON 时弹窗指令区禁用。

### FR-3 安全联锁与急停（P0）

- 见 §5；协议文案原样使用。

### FR-4 平台心跳（P1）

- 卡片 C 展示 ON/OFF；超时规则 10s。

### FR-5 页面集成（P0）

| 入口 | 行为 |
|------|------|
| 垂起全景 · 方舱详情 | 「机库控制」打开**抽屉**（推荐）或内嵌面板，含 §2 布局 |
| 方舱卡片「查看」 | 选中并可直达机库面板 |
| 驾驶舱 | P2：机场窗角标「机库」快览 |

### FR-6 Mock 与类型（P0）

- 全量 mock、无 any；method 元数据表：中文名、级别（L0/L1/L3）、危险级、所属卡片/弹窗。

## 10. 验收标准

1. 主区仅出现 L0/L1/L2，**不出现**归中点动、遥控器、空调、复位、重启工控机等 L3 按钮。  
2. 弹窗可完成全部 L3 指令与环境明细查看。  
3. 联锁 ON：L1/L3 禁用或拒绝，仅 `clear_emergency_stop` 可用；文案与协议一致。  
4. 出/入库、开关机、复位、重启有二次确认。  
5. PLATFORM HB 10s 规则生效。  
6. lint / typecheck / build 通过。
