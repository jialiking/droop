# 机库控制弹窗 — 对偶指令合并设计（v0.3 待确认）

| 项 | 内容 |
|----|------|
| 状态 | 待确认后开发 |
| 范围 | 重构「机库控制」弹窗：**只展示指令按钮**（去掉 OSD 明细）；对偶指令合并为**一个切换按钮** |
| 依据 | APC 协议 method 成对关系 + 已确认安全联锁规则 |

---

## 1. 交互原则

1. **一对相反指令 = 一个按钮**  
   - 按钮文案显示**当前状态**（或下一动作，见 §3 口径待确认）  
   - 点击执行与当前状态相反的 method  
2. **弹窗只放指令**，不放温湿度/状态表等 OSD 展示  
3. **所有指令在同一个弹窗内完成**（含原主面板 L1 与原「更多控制」L3）  
4. 危险操作（出/入库、开关机、复位、重启、急停类）仍需**二次确认**（待确认是否保留）  
5. 清除急停信号 ON 时联锁不变：除允许项外拒绝（协议文案）

---

## 2. 对偶合并表（核心）

| 合并后按钮 | 方法 A | 方法 B | 取值/状态来源（OSD） | 点击行为 |
|------------|--------|--------|----------------------|----------|
| **顶门** | `cover_open` | `cover_close` | `cover_state` 1打开 / 2关闭 / 3运动中 | 关→开；开→关；运动中禁用 |
| **升降平台** | `lifting_platform_up` | `lifting_platform_down` | `lifting_platform_state` 1上升到位 / 2下降到位 / 3运动中 | 下→上；上→下；运动中禁用 |
| **归中** | `position_center_close` | `position_center_open` | `position_center_state` 1夹紧 / 2松开 / 3运动中 | 松开→夹紧；夹紧→松开 |
| **充电夹具** | `charging_center_close` | `charging_center_open` | `charging_center_state` 1伸出 / 2缩回 / 3运动中 | 缩回→伸出；伸出→缩回 |
| **顶门归中** | `door_center_clamp` | `door_center_release` | *协议无独立 OSD*（见 §4 假设） | 本地镜像切换或依赖回执后翻转 |
| **飞机开关机** | `drone_open` | `drone_close` | `device_online_state` | 关→开；开→关 |
| **充放电** | `charging_open` | `charging_close` | `charging_state` | 未充→充电；充电中→停止 |
| **出入库** | `out_bound` | `in_bound` | `drone_in_dock` 或 `in_bound_complete`/`out_bound_complete` | 在库→出库；出库→入库（危险+进度动画） |
| **遥控器** | `remote_control_turn_open_off` | （同一 method 开关） | 本地镜像 | 点击切换开/关 |
| **急停** | `stop` | `clear_emergency_stop` | `stop_state` + 清除急停信号 | OFF→急停；ON→清除急停（特殊） |

### 非对偶（无法合并，单独按钮）

| 按钮 | method | 说明 |
|------|--------|------|
| 机场复位 | `reset` | 单次动作，保持「复位」 |
| 重启工控机 | `restart_pc` | 单次动作 |
| 关空调 | `air_conditioner_close` | 协议仅有「关」；按钮固定「关空调」 |

## 3. 按钮文案口径（请二选一）

| 口径 | 示例（顶门当前=关闭） | 再点后 |
|------|----------------------|--------|
| **A · 显示当前状态**（推荐） | 文案「顶门关闭」+ 关闭态样式 | 执行打开，文案变「顶门打开」 |
| **B · 显示下一动作** | 文案「打开顶门」 | 执行打开，文案变「关闭顶门」 |

本设计默认 **A：按钮即状态，点一下就切换到另一态**。

状态视觉：

- 打开/夹紧/伸出/上升/开机/充电中/出库 → **青色高亮（开态）**
- 关闭/松开/缩回/下降/关机/未充/在库 → **中性（关态）**
- 运动中 `*_state=3` → 橙色 + 禁用点击
- 急停 ON → 红色高亮

## 5. 弹窗布局（仅指令）

```
┌─────────────────────────────────────────────┐
│  机库控制 · 方舱3 / 机场3east            [X] │
├─────────────────────────────────────────────┤
│  ▸ 舱体与升降                               │
│   [ 顶门打开 ]  [ 升降下降 ]  [ 顶门归中 ]   │
│  ▸ 归中与充电                               │
│   [ 归中夹紧 ]  [ 充电夹具缩回 ]  [ 未充电 ] │
│  ▸ 作业与动力                               │
│   [ 在库·出库 ]  [ 飞机关机 ]  [ 遥控器关 ] │
│  ▸ 安全                                     │
│   [ 急停 ]                                  │
│  ▸ 系统与维保                               │
│   [ 机场复位 ]  [ 重启工控机 ]  [ 关空调 ]   │
└─────────────────────────────────────────────┘
```

- **无** OSD 明细表、无环境速览（那些仍可在全景侧栏只读展示，不进本弹窗）  
- 分组标题用弱化文本，主视觉是 10～13 个切换/动作按钮  
- 联锁 ON：除急停/清除急停外禁用 + 顶部一条安全提示（保留文案，不算 OSD）

## 6. 与现有实现的差异

| 现状 | 改后 |
|------|------|
| 侧滑抽屉 + 主卡片状态 + 环境速览 + 更多弹窗 | **设置图标 → 居中弹窗，只含指令** |
| 对偶拆成两个按钮 | **合并为切换按钮** |
| 更多弹窗含 OSD 明细 | **删除 OSD 展示** |
| 出/入库分列 | **合并为出入库切换** |
| 急停/清除急停分列 | **合并为急停切换**（待确认） |

> 若仍需抽屉里的状态总览，可保留抽屉只读、控制全部进弹窗——**请确认是否完全改为弹窗、关闭抽屉**。

## 8. 验收要点

1. 弹窗内可见全部 21 个 method 的操作入口（合并后约 10～13 个控件）。

3. 弹窗内无温湿度/心跳号等 OSD 明细。  
4. 联锁 ON 时行为符合协议。  
5. lint / typecheck / build 通过。
